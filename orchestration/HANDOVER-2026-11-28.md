   Switching `RequestDocumentHandler` to it changes how already-APPROVED templates render.
2. **Encrypt addresses / contact points** — stored and returned in plaintext today (only identifiers and birth date are P2
   encrypted/masked). Changing it is a cross-module encryption decision.
3. **Cash-call threshold** — one configured default EUR 50,000 (`ReinsuranceOptions.CashCallThreshold`, Unverified) for every
   contract, because contracts have no threshold term.
4. **Service role that reveals P2** — `Service.RenewalRun` (POL-10 worker) has `pty.Party.revealP2` for rating; no dedicated
   service-actor grant mechanism yet.
5. **Product release windows not approved** — PFC-04 binds approval to the candidate content; activation date and sales
   windows are set at schedule time and not part of the approval (MKT-02 avoided this for config changes).
